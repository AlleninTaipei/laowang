# 老王用語與轉錄誤字

## 型態用語

| 用語 | 意思 |
| --- | --- |
| 三陽開泰 | 站上三條短期均線 (5 日, 10 日, 20 日), 短線翻多 |
| 四海遊龍 | 均線糾結後站上所有均線 (含季線), 長線翻多 |
| 三聲無奈 | 跌破三條短期均線 (含月線), 短線翻空 |
| 四面楚歌 | 跌破所有均線並帶空方缺口, 長線翻空 |
| 海闊天空 (萬里無雲) | 突破前高壓力後上方沒有套牢壓力 |
| 黃金右腳 / 第二隻腳 | 回測前低守住, 形成 W 底 |
| 一條線玩股票 | 只用一條均線進出; 2025 年後多指 10 日線 (飆股), 台積電短線指月線 |
| 季線生命線 | 季線 (60 日) 是長線多空分界 |
| 凶多吉少 | 跌破爆大量低點後的典型結果 |
| 平地一聲雷 | 底部第一根爆量, 行情發動 |
| 有量才有價, 潛水無大魚 | 量縮沒人氣就漲不動 |
| 看大做小 | 先看國際龍頭或大盤, 再操作個股 |
| 重大輕小 / 拉積盤 | 權值股漲, 中小型股弱 |
| 閃崩王 | 老王自稱, 崩跌前先降水位 |
| 都市傳說 | 老王出國時台股常跌 (玩笑) |
| 加法 | 老王看錯時接受小編 "處罰" 的節目橋段 |

## 缺口

| 用語 | 意思 |
| --- | --- |
| 突破缺口 | 趨勢扭轉的第一個缺口, 被封閉代表大反轉 |
| 中繼缺口 | 趨勢延續, 代表還有高點或低點 |
| 島狀反轉 (左缺右口) | 兩邊缺口包夾的反轉型態 |
| 事件缺口 | 消息衝擊當天的缺口, 封閉代表衝擊消化完 |

## 籌碼與市場用語

| 用語 | 意思 |
| --- | --- |
| 百張以下散戶持股比例 | 集保股權分散表中 100 張以下持股比例, 反指標 |
| 千張大戶 | 1000 張以上持股比例 |
| 外資期貨淨空單 | 外資台指期未平倉淨空口數; 2025 年警戒 4 萬口, 年中後 5 萬口 |
| 四巫日 (三五日) 結算 | 季末衍生性商品同日結算, 大量低點是多空分界 |
| 土洋同買 | 投信與外資同步買超 |
| 隔日沖 | 短線大戶, 買一天賣一天, 不算真外資 |
| 午報 (五報) | 老王給會員的盤中訊息 (約中午) |
| TACO 交易 | 市場看破川普威脅會回頭 |
| 第四大法人 | 2026 年老王對散戶的說法 |
